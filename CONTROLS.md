# Controls

**Azeroth Survivors** — World of Warcraft's own controls: 1.12's movement and camera.

| When | Key / Input | Action |
|---|---|---|
| Menu | Click a race, gender, class and zone | make your pick (**Randomize** rolls one) |
| Menu | **Enter** (or **Enter World**) | start the run; the world travels to the zone picked |
| Playing | **W** / **Up** | run forward, along the way the hero faces |
| Playing | **S** / **Down** | backpedal, at 4.5/7 of the run speed |
| Playing | **A / D** or **Left / Right** | turn left / right (strafe while the right mouse is held) |
| Playing | **Q / E** | strafe left / right |
| Playing | **left mouse** drag | look around the hero; he keeps his facing |
| Playing | **right mouse** drag | turn the camera and the hero with it (steer) |
| Playing | **both mouse buttons** | run forward, steering with the mouse |
| Playing | **Num Lock** / mouse button 4 | autorun (W or S stops it) |
| Playing | **Space** | jump (the jump keeps the direction it left the ground with) |
| Playing | **mouse wheel** | zoom in / out |
| Playing | **F** (from level 5) | your class's movement spell: Blink straight ahead, Charge the foe in front… |
| Any | **G** | toggle the picture polish (`?grade=0` starts it off) |
| Playing | **Esc** | the Main Menu: Sound Options, Interface Options, Logout, Exit Game, Return to Game |
| Playing | — | abilities cast themselves (no aim) |
| Level up | **1 / 2 / 3** (or click a card) | pick an upgrade |
| Main Menu | **Esc** | back out: an options panel cancels, the menu returns to the game |
| Game over | **Enter** (or **Play again**) | back to the menu |
| Any | minimap **+ / −** / minimize | minimap zoom / collapse |

The camera sits behind the hero and, as in WoW's "Smart" following style, swings back behind him
while he moves unless a mouse button holds it. Interface Options sets the mouse sensitivity, invert
mouse, Camera Following Style (Smart / Always / Never), Auto-Follow Speed, Mouse Look Speed and the
Max Camera Distance; Sound Options has the master, sound, music and ambience volumes and the
classic sound switches. Everything is saved. In the menu the camera slowly orbits the preview hero.
Your race, gender, class and zone are remembered across reloads.
